# Unloop Marketing Website

Source code for [unloop.nsaicharan.com](https://unloop.nsaicharan.com).

## Getting Started

```bash
# Install dependencies
npm install

# Start development server (runs on http://localhost:4322)
npm run dev

# Build for production (outputs to ./dist)
npm run build

# Preview build locally
npm run preview
```

## Pages
- `/` - Main landing page with interactive demos, Material 3 theming preview, routines, and app screenshots.
- `/privacy-policy` - Privacy policy covering local app data, permissions, crash diagnostics, and Android backups.
